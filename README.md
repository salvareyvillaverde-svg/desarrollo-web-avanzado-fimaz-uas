## Descripción

Este repositorio contiene las prácticas, ejercicios, exámenes prácticos y el proyecto final desarrollados durante el curso de Desarrollo Web Avanzado.

El objetivo es documentar el proceso de aprendizaje utilizando buenas prácticas de desarrollo y control de versiones con Git y GitHub.

---

## Estructura del repositorio

- Parcial 1 – Programación Orientada a Objetos (POO)
- Parcial 2 – PDO y MySQL
- Parcial 3 – Arquitectura MVC
- Parcial 4 – API REST
- Proyecto Final
