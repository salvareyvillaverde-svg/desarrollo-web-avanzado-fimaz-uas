# Práctica 1 - Clase Usuario

## Objetivo
Crear una clase en PHP utilizando encapsulamiento.

## Descripción
Se implementó una clase llamada Usuario con los atributos privados nombre y correo.

Se implementaron los métodos:
- Constructor
- getNombre()
- getCorreo()
- setNombre()
- setCorreo()

2. Abrir el navegador.
