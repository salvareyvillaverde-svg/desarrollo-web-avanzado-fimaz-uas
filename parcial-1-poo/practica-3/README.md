# Práctica 3 – Manejo de excepciones en PHP

## Descripción
Se implementa un sistema básico de usuarios utilizando Programación Orientada a Objetos.

## Flujo del sistema
Usuario es la clase base.
Admin y Alumno heredan de Usuario.

Se valida el correo utilizando filter_var y se lanza una excepción si es inválido.

## Manejo de errores
Se utiliza try/catch para capturar excepciones y mostrar mensajes controlados.
